# PS Multi Timer - عدّادات بلايستيشن 🎮

تطبيق لتتبع وقت جلسات PlayStation مع حساب السعر تلقائياً.

## الميزات
- عدّادات متعددة (Stopwatch + Countdown)
- تسعير تلقائي: 50 دج / 15 دقيقة
- تنبيه صوتي عند انتهاء العدّ التنازلي
- حفظ البيانات حتى بعد إغلاق التطبيق
- سحب وإسقاط لترتيب العدّادات
- تقويم الإيرادات اليومية/الأسبوعية/الشهرية
- لوحة إعدادات كاملة (خطوط، ألوان، تخطيط...)
- يعمل بدون إنترنت

## كيفية بناء ملف .exe

### المتطلبات
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- Windows 10 أو 11

### خطوات البناء

```bash
# 1. ادخل مجلد المشروع
cd ps-timer

# 2. ثبّت المكتبات
npm install

# 3. ابنِ ملف exe
npm run build-portable
```

سيُنشأ ملف `PS-Multi-Timer.exe` في مجلد `dist/`

### تشغيل بدون بناء
يمكنك أيضاً فتح ملف `PS-Timer.html` مباشرة في أي متصفح على Windows 10/11 وسيعمل كتطبيق ويب كامل.

## استخدام كتطبيق ويب مباشرة
فقط افتح `PS-Timer.html` في متصفح Chrome أو Edge - يعمل بدون أي سيرفر!
